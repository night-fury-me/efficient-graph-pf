% Figure: Method-positioning RADAR (spider) chart -- AEGIS vs the two prior
% threads it is directly comparable to on AUDIT + CERTIFY + COST: structural
% attacks and certifiers. Honest variant of the capability matrix
% (fig_positioning): seven axes scored on [0,1] (0 = centre, 1 = outer ring)
% under FRONTIER semantics -- each polygon traces the BEST its research thread
% achieves on each axis -- and DELIBERATELY includes axes where rivals win, so
% no method fills the space (defuses the strawman concern, editorial item C-DA2).
%
% NOTE: AEGIS's third pillar (DEFENSE: the sigma_1(S_c) training penalty) is NOT
% an axis here. It is a different kind of claim, benchmarked against the
% robust-architecture thread in its own subsection (sec:defense, tab:defense);
% putting it on this radar would (i) double-count the per-node-certificate axis
% for the certifier polygon (their robustness and their certificate share one
% mechanism) and (ii) score an axis we do not benchmark head-to-head. Kept off.
%
% Score rationale (frontier semantics; verified line-by-line against the cited
% papers -- see paper/review/radar_competitor_audit.md):
%   Attack direction    Attacks 1.0 (white-box / meta-gradient define the attack
%                        direction: Nettack score fn, Mettack grad_A, PR-BCD
%                        continuous edge prob.) | AEGIS 0.9 (closed-form SVD
%                        proxy, prop:attack) | Certifiers 0.0
%   Per-edge attribution Attacks 1.0 (per-edge gradient IS the oracle ranking) |
%                        AEGIS 0.9 (||[S_c]_{:,k}||; tau 0.16-0.99 vs that oracle) |
%                        Certifiers 0.0 (name no edges)
%   Large-budget damage  Attacks 1.0 (GR-BCD/PR-BCD at scale, large budgets) |
%                        AEGIS 0.5 (one-query early-warning regime) | Cert. 0.0
%   Per-node certificate Certifiers 1.0 (AGNNCert deterministic per-node radius;
%                        localized smoothing is a COLLECTIVE cert) | AEGIS 0.65
%                        (first-order r_v + conformal) | Attacks 0.0
%   Query efficiency     AEGIS 1.0 (one S_c query) | Certifiers 0.85 (AGNNCert
%                        deterministic, T=30-80 subgraph evals; localized smoothing
%                        ~5e5 samples/node sits near 0) | Attacks 0.3 (50-500 grad
%                        epochs; Nettack greedy cheaper)
%   No retraining        AEGIS 1.0 and evasion attacks 1.0 (off-the-shelf model;
%                        GR-/PR-BCD are evasion, fixed-theta) | Certifiers 0.2
%                        (noise-/subgraph-augmented training)
%   Label-free           AEGIS 1.0 (no labels in the S_c query) | Certifiers 0.9
%                        (certify the predicted class) | Attacks 0.1 (loss needs labels)
% Attacks own damage/direction/edges; certifiers own the per-node certificate;
% AEGIS wins no specialist axis outright but is the only polygon with nonzero
% mass on all seven axes.
% Okabe-Ito palette, mathptmx serif 11pt: consistent with the other figures.
