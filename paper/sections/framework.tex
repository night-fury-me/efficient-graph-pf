\section{The \AEGIS Operator: One Object, Three Diagnostics}
\label{sec:framework}
%% ===================================================================

The previous section isolated the two Jacobians, $J_z$ and $J_A$, through which the adjacency moves the equilibrium. \AEGIS packages them into a single operator, the constrained sensitivity matrix $S_c$, and reads every diagnostic off it. One $S_c$ computation returns the per-edge vulnerability spectrum $\{v_{ij}\}$, the SVD-optimal attack direction $\delta\Ahat^\star$, and the per-node safe radii $\{r_v\}$, together with $\ecrit$ and the regime characterisation of \cref{thm:phase_transition} for IGNN-class operators. None of this requires building $S_c$ explicitly: the pipeline only ever applies it to vectors, so it never materialises $S \in \R^{Nd \times N^2}$ or forms the resolvent. A dense path ($N \leq 200$) takes an exact SVD; a matrix-free path ($N > 200$, validated to $N{=}7{,}650$) uses JVP/VJP queries and a randomized SVD. \Cref{fig:pipeline} illustrates the four stages and \cref{alg:aegis} the routing between the two paths.

\begin{algorithm}[H]
\caption{\AEGIS matrix-free vulnerability analysis. $S_c$ is queried but never formed; the dense fallback ($N\!\leq\!200$) builds $S_c$ and runs an exact SVD.}
\label{alg:aegis}
\begin{algorithmic}[1]
\REQUIRE $F$, fixed point $\zstar$, $\Ahat$, edge set $E$, budget $\varepsilon$, rank $k$, Neumann tolerance $\mathrm{tol}$; (opt.)\ head $W$, margins $m_v^{(c)}$.
\ENSURE $\sigma_1(S_c),\ \delta\Ahat^{\star},\ \{v_{ij}\},\ \{r_v\},\ \ecrit$.
\STATE $\kappa \leftarrow \norm{J_z}_2$;\quad $K \leftarrow \lceil \log(1/\mathrm{tol})/\log(1/\kappa)\rceil$
\STATE $S_c\,v := \big(\textstyle\sum_{j=0}^{K} J_z^{j}\big)\,J_A\,P_c\,v$ \COMMENT{matrix-free}
\STATE $(\sigma_1, v_1) \leftarrow \mathrm{rSVD}(S_c,\,k)$~\cite{halko2011finding}
\STATE $\delta\Ahat^{\star} \leftarrow \varepsilon\,\mathrm{sym}(P_c v_1)\,/\,\norm{\mathrm{sym}(P_c v_1)}_2$
\STATE $v_{ij} \leftarrow \norm{S_c\,e_{ij}}_2$\ \ for each $(i,j)\in E$
\STATE $r_v \leftarrow \min_{c\neq y_v} m_v^{(c)} / \norm{(W_{y_v}{-}W_c)\,S_{c,v}}_2$ \COMMENT{head only}
\STATE $\ecrit \leftarrow (1-\kappa)/\norm{W}_2$ \COMMENT{\cref{thm:phase_transition}}
\STATE \textbf{return} $(\sigma_1,\ \delta\Ahat^{\star},\ \{v_{ij}\},\ \{r_v\},\ \ecrit)$
\end{algorithmic}
\end{algorithm}

\textbf{The constrained sensitivity operator.} Intuitively, $S_c$ is the full sensitivity $S$ cut down to the perturbations the threat model actually permits: one column per existing edge, symmetrised so that touching edge $(i,j)$ also touches $(j,i)$. Formally, $S_c \in \R^{Nd \times |E|}$ has columns $[S_c]_{:,k} = S_{:,iN+j} + S_{:,jN+i}$ in the edge basis $b_k{=}(e_i e_j^\top + e_j e_i^\top)/\sqrt{2}$; each $b_k$ has unit Frobenius norm, so $\sigma_1(S_c)$ is measured consistently with the budget $\norm{\delta\Ahat}_F{=}\varepsilon$. The $N^2 \to |E|$ projection $P_c$ that performs this restriction is the standard duplication-matrix reduction~\cite{magnus2019matrix} onto the edge-supported symmetric subspace. A single randomized SVD of $S_c$ then reads off all three diagnostics: \emph{(i)} the optimal attack direction (\cref{prop:attack}); \emph{(ii)} the per-edge vulnerability ranking $v_{ij}{=}\norm{[S_c]_{:,k}}_2$; and \emph{(iii)} the per-node safe radius $r_v$, whose first-order guarantee we prove in \cref{prop:radius} (\cref{sec:theory}). Together these three readings are what it means to \emph{audit} the model. The same operator then \emph{certifies} it, because the radius upgrades to a distribution-free guarantee (\cref{sec:conformal}), and \emph{defends} it, because penalizing $\sigma_1(S_c)$ trades clean accuracy for certified robustness (\cref{sec:defense}).

\begin{proposition}[Maximally Sensitive First-Order Structural Perturbation]
\label{prop:attack}
The perturbation $\delta A^*$ maximizing $\norm{\Delta \zstar}$ to first order subject to $\norm{\delta A}_F \leq \varepsilon$ is $\delta A^* = \varepsilon \cdot \mathrm{reshape}(v_1, N \times N)$, where $v_1$ is the leading right singular vector of $S$, with shift $\varepsilon \cdot \sigma_1(S)$. Restricted to the threat model's feasible set (symmetric, edge-supported; \cref{sec:background}) the maximizer is instead the leading right singular vector of the constrained $S_c$ in the edge basis $\{b_k\}$, with shift $\varepsilon\,\sigma_1(S_c){\leq}\varepsilon\,\sigma_1(S)$; the unconstrained $\mathrm{reshape}(v_1)$ is generally infeasible.
\end{proposition}

This direction maximises hidden-state shift rather than label change, so it pinpoints the most dangerous way to spend the budget rather than certifying a global safety margin (\cref{sec:cross_domain}); the gap to that margin is the pseudospectral envelope of \cref{obs:eta_bound,rem:eta_relu}. Empirically the direction nonetheless aligns with classification damage (\cref{sec:adaptive}).

\textbf{Matrix-free operator.} Scale rests on never building $S_c$: we only ever apply it to vectors, which costs $O(Nd)$ memory instead of the $O((Nd)^2)$ a dense $S_c$ would need. The key product $S_c v = (I{-}J_z)^{-1}J_A P_c v$ is evaluated with a truncated Neumann series $\sum_{k=0}^K J_z^k b$, whose depth $K$ adapts to $\kappa$ and stops early once $\norm{J_z^k b}<10^{-6}\norm{b}$. Every Neumann term, like the product $J_A\,\mathrm{vec}(\delta A)$, is a forward-mode JVP costing $O(Nd)$ with $P_c$ applied implicitly; the dense path ($N\leq 200$) instead materialises $J_z, J_A$ and solves directly. The randomized SVD~\cite{halko2011finding} ($k{=}p{=}10$, $n_\mathrm{iter}{=}2$) returns $(u_1,\sigma_1,v_1)$, and symmetrising through $\mathrm{sym}(M){=}(M{+}M^\top)/2$ keeps the recovered attack $\delta\Ahat^\star{=}\varepsilon\,\mathrm{sym}(P_c v_1)$ inside the threat model (\cref{sec:background}). One query suffices because the singular spectrum is well separated (gap $(\sigma_1{-}\sigma_2)/\sigma_1{=}0.39$--$0.50$; \cref{fig:sc_heatmap}), and that separation is what lets a single rSVD match iterative attackers (\cref{sec:adaptive}).

\textbf{Cost.} Each $S_c v$ is $O(K{\cdot}Nd)$ time and $O(Nd)$ memory ($K{\in}[20,50]$ for $\kappa{<}0.8$); removing the $O((Nd)^3)$ solve lifts the previous $N{\approx}300$ ceiling (\cref{app:phase_scal}).
