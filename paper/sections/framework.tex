\section{The \AEGIS Operator Construction}
\label{sec:framework}
%% ===================================================================

The previous section isolated the two Jacobians, $J_z$ and $J_A$, through which the adjacency moves the equilibrium. \AEGIS packages them into one operator, the constrained sensitivity matrix $S_c$, never formed explicitly but only applied to vectors (\cref{alg:aegis}). \Cref{fig:pipeline} shows the four stages.

\textbf{The constrained sensitivity operator.} $S_c$ is the full sensitivity $S$ cut down to the perturbations the threat model permits: one column per existing edge, symmetrised so that touching edge $(i,j)$ also touches $(j,i)$. The edge basis has unit Frobenius norm, so $\sigma_1(S_c)$ matches the budget $\norm{\delta\Ahat}_F{=}\varepsilon$; the $N^2 \to |E|$ restriction $P_c$ is the standard duplication-matrix reduction~\cite{magnus2019matrix} onto the edge-supported symmetric subspace. One randomized SVD of $S_c$ yields the three audit readings together: the optimal attack direction (\cref{prop:attack}), the per-edge ranking $v_{ij}{=}\norm{[S_c]_{:,k}}_2$, and the per-node radius $r_v$ (\cref{prop:radius}). The same operator then \emph{certifies} the model (\cref{sec:conformal}) and \emph{defends} it (\cref{sec:defense}).

\begin{algorithm}[H]
\caption{\AEGIS matrix-free vulnerability analysis. $S_c$ is queried but never formed; the dense fallback ($N\!\leq\!200$) builds $S_c$ and runs an exact SVD.}
\label{alg:aegis}
\begin{algorithmic}[1]
\REQUIRE $F$, fixed point $\zstar$, $\Ahat$, edge set $E$, budget $\varepsilon$, rank $k$, Neumann tolerance $\mathrm{tol}$; (opt.)\ head $W$, margins $m_v^{(c)}$.
\ENSURE $\sigma_1(S_c),\ \delta\Ahat^{\star},\ \{v_{ij}\},\ \{r_v\},\ \ecrit$.
\STATE $\kappa \leftarrow \norm{J_z}_2$;\quad $K \leftarrow \lceil \log(1/\mathrm{tol})/\log(1/\kappa)\rceil$
\STATE $S_c\,v := \big(\textstyle\sum_{j=0}^{K} J_z^{j}\big)\,J_A\,P_c\,v$ \COMMENT{matrix-free}
\STATE $(\sigma_1, v_1) \leftarrow \mathrm{rSVD}(S_c,\,k)$~\cite{halko2011finding}
\STATE $\delta\Ahat^{\star} \leftarrow \varepsilon\,\mathrm{sym}(P_c v_1)\,/\,\norm{\mathrm{sym}(P_c v_1)}_2$
\STATE $v_{ij} \leftarrow \norm{S_c\,e_{ij}}_2$\ \ for each $(i,j)\in E$
\STATE $r_v \leftarrow \min_{c\neq y_v} m_v^{(c)} / \norm{(W_{y_v}{-}W_c)\,S_{c,v}}_2$ \COMMENT{head only}
\STATE $\ecrit \leftarrow (1-\kappa)/\norm{W}_2$ \COMMENT{\cref{thm:phase_transition}}
\STATE \textbf{return} $(\sigma_1,\ \delta\Ahat^{\star},\ \{v_{ij}\},\ \{r_v\},\ \ecrit)$
\end{algorithmic}
\end{algorithm}

\begin{proposition}[Maximally Sensitive First-Order Structural Perturbation]
\label{prop:attack}
The perturbation $\delta A^*$ maximizing $\norm{\Delta \zstar}$ to first order subject to $\norm{\delta A}_F \leq \varepsilon$ is $\delta A^* = \varepsilon \cdot \mathrm{reshape}(v_1, N \times N)$, where $v_1$ is the leading right singular vector of $S$, with shift $\varepsilon \cdot \sigma_1(S)$. Restricted to the threat model's feasible set (symmetric, edge-supported; \cref{sec:background}) the maximizer is instead the leading right singular vector of the constrained $S_c$ in the edge basis $\{b_k\}$, with shift $\varepsilon\,\sigma_1(S_c){\leq}\varepsilon\,\sigma_1(S)$; the unconstrained $\mathrm{reshape}(v_1)$ is generally infeasible.
\end{proposition}

This direction maximises hidden-state shift, not label change, so it pinpoints the most dangerous use of the budget rather than certifying a global margin, yet still aligns empirically with classification damage (\cref{sec:adaptive}).

\textbf{Matrix-free operator.} Scale rests on never forming $S_c$. Every reading is a product $S_c v$, so we keep it as the operator $S_c v = (I{-}J_z)^{-1}J_A P_c v$ and apply it in $O(Nd)$ memory rather than store the $O((Nd)^2)$ dense matrix. Its one hard factor is the resolvent $(I{-}J_z)^{-1}$, which contractivity ($\kappa{<}1$) expands as a geometrically convergent Neumann series ($K{\in}[20,50]$ for $\kappa{<}0.8$), each term a forward-mode JVP that applies $P_c$ implicitly; only for $N\leq 200$ do we form $J_z,J_A$ directly. A randomized SVD~\cite{halko2011finding} returns the leading $(\sigma_1,v_1)$, symmetrised so the recovered attack stays in the threat model. One query suffices because the singular spectrum is well separated (gap $0.39$--$0.50$; \cref{fig:sc_heatmap}), which lets a single rSVD match iterative attackers (\cref{sec:adaptive}); removing the $O((Nd)^3)$ dense solve lifts the previous $N{\approx}300$ ceiling to $N{=}7{,}650$ (\cref{app:phase_scal}).
