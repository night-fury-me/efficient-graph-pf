\section{\AEGIS Construction}
\label{sec:framework}
%% ===================================================================

The pipeline makes the theory of \cref{sec:theory} practical: it queries $S_c$ matrix-free, never materialising $S \in \R^{Nd \times N^2}$ or forming the resolvent. One $S_c$ computation returns the per-edge spectrum $\{v_{ij}\}$, the SVD-optimal direction $\delta\Ahat^\star$, and per-node radii $\{r_v\}$, plus $\ecrit$ and the regime characterisation of \cref{thm:phase_transition} for IGNN-class operators. A dense path ($N \leq 200$) computes an exact SVD; a matrix-free path ($N > 200$, validated to $N{=}7{,}650$) uses JVP/VJP queries and randomized SVD. \Cref{fig:pipeline} illustrates the four stages; \cref{alg:aegis} (\cref{app:algorithm}) gives the routing.

\textbf{Matrix-free operator.} Scaling rests on never building $S_c$: we only apply it to vectors, needing $O(Nd)$ memory rather than the $O((Nd)^2)$ a dense $S_c$ costs. Concretely, $S_c v = (I{-}J_z)^{-1}J_A P_c v$ is evaluated via the truncated Neumann series $\sum_{k=0}^K J_z^k b$ with depth $K$ adaptive in $\kappa$ (early stop at $\norm{J_z^k b}<10^{-6}\norm{b}$), each Neumann term and $J_A\,\mathrm{vec}(\delta A)$ being forward-mode JVPs in $O(Nd)$ time with $P_c$ applied implicitly; the dense path ($N\leq 200$) materialises $J_z, J_A$ and uses a direct solve. The rSVD~\cite{halko2011finding} ($k{=}p{=}10$, $n_\mathrm{iter}{=}2$) returns $(u_1,\sigma_1,v_1)$ for the direction $\delta\Ahat^\star{=}\varepsilon\,\mathrm{sym}(P_c v_1)$ (\cref{prop:attack}), with $\mathrm{sym}(M){=}(M{+}M^\top)/2$ keeping $\delta\Ahat^\star$ symmetric (\cref{sec:background}); column norms give $\{v_{ij}\}$ and per-node radii follow \cref{prop:radius}. The well-separated singular spectrum (gap $(\sigma_1{-}\sigma_2)/\sigma_1{=}0.39$--$0.50$; \cref{fig:sc_heatmap}) is why one rSVD query matches iterative attackers (\cref{sec:adaptive}).

\textbf{Cost.} Each $S_c v$ is $O(K{\cdot}Nd)$ time and $O(Nd)$ memory ($K{\in}[20,50]$ for $\kappa{<}0.8$); removing the $O((Nd)^3)$ solve lifts the previous $N{\approx}300$ ceiling (\cref{app:phase_scal}).
