\section{Conclusion}
\label{sec:conclusion}
%% ===================================================================

\AEGIS provides a principled, architecture-agnostic pre-deployment diagnostic for GNNs on safety-critical graphs: from a single $S_c$ computation, practitioners obtain the first-order optimal attack direction, per-edge vulnerability rankings, and per-node tolerance budgets. The $S_c$ framework applies to any GNN with continuous edge-weight-modulated message passing; for contractive implicit models, supplementary formal guarantees ($\ecrit$, three vulnerability regimes) additionally characterize model behavior. Predictions remain within 15\% of ground truth at $\varepsilon = 0.10$ across 7 architectures and 9 datasets, and the vulnerability spectrum transfers to power grid contingency analysis (P@10 = 0.66--0.87). The per-edge ranking directly informs defense design (\cref{sec:defense_ablation}).

\textbf{Limitations.} (1)~First-order sensitivity radii are locally tight but not global certificates without second-order bounds. (2)~Continuous edge-weight perturbations; discrete insertions/deletions are outside the formal guarantee, though continuous $S_c$ rankings transfer well to discrete removal ($\tau = +0.22$--$+0.54$; \cref{tab:explicit}). (2b)~On dense graphs (e.g., Amazon Photo, avg.\ degree $\sim$31), IGNN subgraph analysis yields weak $\tau$ due to low subgraph $\kappa$ and near-uniform discrete damage; full-graph matrix-free analysis partially recovers ($\tau$: $-0.14 \to +0.03$), and explicit GNNs transfer well (SAGE-2: $+0.60$). (3)~Standard GAT requires edge-weighted modification for continuous sensitivity. (4)~Power flow $\tau = 0.37$--$0.67$ requires verification for operational use~\cite{wood2014power}. (5)~The matrix-free pipeline's Neumann series requires $\kappa < 1$; for explicit GNNs without contractivity, the dense path ($N \leq 200$) or finite-difference columns are used. (6)~IGNN accuracy (77.5\% on Cora) lags behind state-of-the-art explicit GNNs ($\sim$82\% APPNP); this reflects the accuracy--guarantee tradeoff inherent in contractive architectures, not a limitation of \AEGIS itself. The $S_c$ framework applies identically to higher-accuracy explicit models, albeit without the formal regime characterization (\cref{thm:phase_transition}).

\textbf{Ethical considerations.} \AEGIS identifies optimal attack directions and structurally vulnerable edges, which could be misused to attack deployed GNNs in safety-critical domains. We argue the diagnostic value outweighs this risk: defenders must understand their system's attack surface to protect it, and the same vulnerability map directly informs defense design (\cref{sec:defense_ablation}). We will release code with responsible-use guidelines, including a tiered release protocol: vulnerability analysis tools (rankings, radii) will be openly available, while the attack-generation component (SVD-optimal perturbation direction) will require institutional affiliation for access, consistent with established practice in adversarial ML~\cite{wu2019adversarial}.

\textbf{Future work.} Second-order bounds for formal certificates; discrete perturbation models; integration with defense mechanisms~\cite{jin2020graph,zhang2020gnnguard} for vulnerability-aware training; extending full-graph analysis beyond the current validated boundary ($N{=}7{,}650$ on a single GPU) via distributed JVP computation; and admittance-weighted adjacency for power flow applications where line impedance modulates electrical coupling (the $S_c$ framework requires only differentiability of message passing with respect to edge weights, which admittance-weighted GNNs satisfy).
