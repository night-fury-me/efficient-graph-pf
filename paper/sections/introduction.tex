\section{Introduction}
\label{sec:intro}
%% ===================================================================

Graph neural networks are vulnerable to adversarial structural perturbation: small changes to graph topology can drastically alter predictions~\cite{zugner2018adversarial,zugner2019adversarial,dai2018adversarial,xu2019topology}. Defending against such attacks requires understanding which perturbations matter and by how much. Empirical defenses such as robust aggregation~\cite{zhu2019robust,zhang2020gnnguard} and graph structure learning~\cite{jin2020graph,luo2021learning} improve resilience but lack formal guarantees. Certified approaches either provide probabilistic bounds via randomized smoothing~\cite{bojchevski2020efficient,scholten2022randomized}, require layer-by-layer propagation tied to specific architectures~\cite{zugner2019certifiable,bojchevski2019certifiable,wang2021certified}, or target explicit models exclusively~\cite{li2025agnncert,jin2021adversarial}. None provides a unified structural vulnerability analysis that works across GNN families.

We introduce AEGIS, a framework built on a single object: the \emph{constrained sensitivity matrix} $S_c$, which maps symmetric, edge-only perturbations of the adjacency matrix to hidden-state shifts. The $S_c$ computation applies to any differentiable GNN: for a $K$-layer model, $S_c$ is derived from the unrolled Jacobian $\partial Z_K / \partial A$ (\cref{prop:explicit}); for contractive implicit GNNs (IGNN-class~\cite{gu2020implicit}), $S_c$ is derived from the equilibrium sensitivity $S = (I - J_z)^{-1} J_A$ via the implicit function theorem, which additionally provides a critical perturbation budget $\ecrit$ and convergence guarantees (\cref{thm:phase_transition}) not available for explicit architectures. In both cases, $S_c$ yields: (i) an SVD-optimal structural attack, (ii) a per-edge vulnerability ranking, and (iii) per-node first-order sensitivity radii (locally tight but not global certificates without second-order bounds).

The central finding is that constrained first-order predictions via $S_c$ achieve tightness $1.00 \pm 0.01$ at $\varepsilon = 0.01$ and remain within 15\% at $\varepsilon = 0.10$ across 7 GNN architectures (IGNN, GCN, GIN, GAT, GraphSAGE, APPNP) and 9 datasets spanning 4 domains.

\textbf{Contributions.}
\begin{enumerate}
\item \textbf{Constrained sensitivity framework.} We derive the constrained sensitivity matrix $S_c$ for any differentiable GNN (\cref{prop:explicit}). For contractive implicit models, we additionally prove a critical budget $\ecrit = (1-\kappa)/\norm{W}_2$ and three vulnerability regimes (\cref{thm:phase_transition}) that characterize when first-order guarantees hold.

\item \textbf{Unified vulnerability analysis.} From $S_c$ we extract SVD-optimal attacks (2--8$\times$ stronger than random across all architectures), per-edge vulnerability spectra, and per-node first-order sensitivity radii. We validate on 7 architectures: IGNN~\cite{gu2020implicit}, GCN~\cite{kipf2017semi}, GIN, GAT, GraphSAGE, and APPNP (\cref{sec:explicit_extension}).

\item \textbf{Cross-domain validation.} We validate across 9 datasets in 4 domains: citation networks~\cite{sen2008collective}, e-commerce~\cite{shchur2018pitfalls}, encyclopedia~\cite{mernyei2020wiki}, and IEEE power grids~\cite{ieee2024testcases}. The vulnerability spectrum recovers power grid N-1 contingency rankings with precision@10 = $0.66$--$0.81$ (\cref{sec:power_flow}).
\end{enumerate}
