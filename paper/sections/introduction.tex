\section{Introduction}
\label{sec:intro}
%% ===================================================================

Graph neural networks are deployed in domains where prediction failures carry real cost: fraud detection on financial networks~\cite{zugner2018adversarial}, drug interaction prediction~\cite{dai2018adversarial}, and power grid monitoring~\cite{nakiganda2023graph}. A fundamental question for any such deployment is: \emph{how much structural perturbation can this model tolerate, and which edges are the weak points?}

Existing tools cannot answer this. Empirical defenses~\cite{zhu2019robust,zhang2020gnnguard,jin2020graph} improve robustness without revealing \emph{where} vulnerability remains. Certified approaches~\cite{bojchevski2020efficient,bojchevski2019certifiable} provide global bounds but treat all edges uniformly. Attack methods~\cite{zugner2019adversarial,xu2019topology} find adversarial perturbations without optimality guarantees or per-node quantification. None provides a structural vulnerability map for deployment decisions.

We introduce AEGIS, a pre-deployment diagnostic that produces a \emph{structural vulnerability map} for any trained GNN, answering: (1)~what is the optimal attack direction? (2)~which edges are weakest? (3)~how much perturbation can each node tolerate? All three derive from the \emph{constrained sensitivity matrix} $S_c$, computable for any differentiable GNN. For contractive implicit models (IGNN-class~\cite{gu2020implicit}), $S_c$ additionally provides a critical budget $\ecrit$ and convergence guarantees (\cref{thm:phase_transition}). The predictions are tight: $1.00 \pm 0.01$ at $\varepsilon = 0.01$, within 15\% at $\varepsilon = 0.10$, across 7 architectures and 9 datasets.

\textbf{Contributions.}
\begin{enumerate}
\item \textbf{Constrained sensitivity framework.} We derive the constrained sensitivity matrix $S_c$ for any differentiable GNN (\cref{prop:explicit}). For contractive implicit models, we additionally prove a critical budget $\ecrit = (1-\kappa)/\norm{W}_2$ and three vulnerability regimes (\cref{thm:phase_transition}) that characterize when first-order guarantees hold.

\item \textbf{Unified vulnerability analysis.} From $S_c$ we extract SVD-optimal attacks (2--8$\times$ stronger than random across all architectures), per-edge vulnerability spectra, and per-node first-order sensitivity radii. We validate on 7 architectures: IGNN~\cite{gu2020implicit}, GCN~\cite{kipf2017semi}, GIN, GAT, GraphSAGE, and APPNP (\cref{sec:explicit_extension}).

\item \textbf{Cross-domain validation.} We validate across 9 datasets in 4 domains: citation networks~\cite{sen2008collective}, e-commerce~\cite{shchur2018pitfalls}, encyclopedia~\cite{mernyei2020wiki}, and IEEE power grids~\cite{ieee2024testcases}. The vulnerability spectrum recovers power grid N-1 contingency rankings with precision@10 = $0.66$--$0.81$ (\cref{sec:power_flow}).
\end{enumerate}
