\begin{abstract}
We introduce AEGIS (Adversarial Evaluation of Graph Integrity via Sensitivity), a framework for analyzing adversarial vulnerability of graph neural networks under structure perturbation. AEGIS constructs a constrained sensitivity matrix $S_c$ that maps symmetric, edge-only perturbations to hidden-state shifts, enabling SVD-optimal attacks, per-edge vulnerability ranking, and per-node first-order robustness radii. The framework applies to any differentiable GNN: for a $K$-layer model, $S_c$ is derived from the unrolled Jacobian $\partial Z_K / \partial A$; for contractive implicit GNNs (IGNN-class), it is derived from the equilibrium sensitivity $(I - J_z)^{-1} J_A$, which additionally yields a critical budget $\ecrit = (1-\kappa)/\norm{W}_2$ and convergence guarantees. Under constrained perturbations, first-order predictions achieve tightness $1.00 \pm 0.01$ at $\varepsilon = 0.01$ across 7 architectures (IGNN, GCN, GIN, GAT, GraphSAGE, APPNP) and 9 datasets (10 seeds each). The SVD-optimal attack inflicts 2--8$\times$ more damage than random perturbation across all models. As a case study, the vulnerability spectrum recovers power grid N-1 contingency rankings with precision@10 between 0.66 and 0.81. Code will be released upon publication.
\end{abstract}
