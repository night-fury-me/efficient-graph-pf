\section{Case Study: Power Flow Contingency}
\label{sec:power_flow}
%% ===================================================================

The experiments above validate AEGIS on standard graph benchmarks. A natural question is whether the vulnerability spectrum captures meaningful structure beyond these benchmarks. We demonstrate on a fundamentally different domain, AC power flow, where the adversarial vulnerability spectrum recovers a classical engineering problem: N-1 contingency analysis. Recent work has applied GNNs to power flow computation~\cite{donon2019graph,bolz2019power} and contingency screening~\cite{nakiganda2023graph}; AEGIS approaches the same problem from the vulnerability-analysis perspective.

\subsection{Background: N-1 Contingency}

Power grid operators must ensure that no single transmission line failure causes system instability. The standard N-1 contingency assessment removes each line in turn, re-solves the power flow equations, and ranks lines by the severity of the resulting voltage and flow deviations~\cite{wood2014power}. This brute-force procedure scales as $O(|E|)$ full power flow solves, which is expensive for large grids and infeasible for real-time operation.

We observe that AEGIS's per-edge vulnerability $v_{ij} = \norm{[S_c]_{:,k}}_2$ computes an analogous quantity via a single IFT analysis: edge perturbation maps to line trips, the vulnerability spectrum maps to contingency severity, and critical budget $\ecrit$ maps to stability margin. The correspondence is approximate (continuous first-order vs.\ discrete removal), analogous to how PTDF/LODF~\cite{wood2014power} linearize the effect of line trips.

\subsection{Experimental Setup}

We train ContractiveGCN-PF, an IGNN variant for AC power flow, on four standard IEEE test cases~\cite{ieee2024testcases}. Training data is generated via PandaPower's~\cite{thurner2018pandapower} full AC Newton-Raphson solver (2,000 load samples per case, uniformly sampled at 70--130\% of nominal load). The model takes binary adjacency from the admittance matrix and 5 bus features: bus type indicators (slack, PV), active and reactive power injections (P, Q), and voltage magnitude $|V|$. Unlike graph benchmarks, power flow grids are small enough (14--118 buses) to analyze without subgraph extraction.

\textbf{Limitation.} Training data covers uniform load scaling (2,000 samples) but not seasonal or generator-outage variation.

\textbf{Key observations.} First, tightness transfers to the power flow domain ($\approx 1.00$), confirming that the first-order prediction is not domain-specific. Second, ranking correlation ($\tau = 0.37$--$0.67$) is moderate but the operationally relevant P@10 is 0.66--0.81, correctly identifying 7--8 of the top 10 critical lines.

\textbf{Implicit physics from equilibrium structure.} The model is trained with voltage MSE alone --- no power-balance penalty. Yet the per-bus residual $\Delta S = 0.03$--$0.11$ p.u.\ (\cref{tab:ieee}), meaning predicted voltages approximately satisfy Kirchhoff's laws without explicit enforcement. This arises from the DEQ architecture: at equilibrium, $Z^* = F(Z^*, A)$ forces the hidden state to be self-consistent with the grid topology in $A$. Perturbations that disrupt this self-consistency (identified by AEGIS) are precisely those that break the power balance, connecting structural vulnerability directly to physical contingency.

\textbf{Baseline comparison.} LODF (industry-standard DC screening~\cite{wood2014power}) achieves $\tau = 0.44$--$0.58$; AEGIS outperforms on larger grids ($\tau = 0.62$--$0.67$ on case57/118) by capturing nonlinear AC effects. LODF requires line reactances; AEGIS requires only the trained model.

\textbf{Practical positioning.} For case118, AEGIS ranks in 2.3s (single IFT) vs.\ 179 full AC solves for brute-force N-1, achieving P@10 = 0.81. Binary adjacency outperforms admittance-weighted (P@10 = 0.81 vs.\ 0.27) because N-1 contingency is a discrete event better modeled by uniform sensitivity.

\textbf{Operational caveat.} AEGIS is a screening layer, not a standalone contingency tool ($\tau = 0.37$--$0.67$ is insufficient for direct operational use).
